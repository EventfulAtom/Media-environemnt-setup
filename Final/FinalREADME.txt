# Cube Survival Game
A fast-paced, arcade-style game where you control a cube to dodge walls and survive for 60 seconds. Inspired by Flappy Bird, but with simpler, direct controls.
# Gameplay Overview
Control a cube using the up and down arrow keys. The objective is to survive for 60 seconds by avoiding red walls. If you hit a wall, you lose. No need to flap like in Flappy Bird—just steer with precision!
# Controls
- Up Arrow – Move cube up  
- Down Arrow – Move cube down
# Win / Lose
Only way to win is by survining the full 60 seconds, if you don't you lose! 
Good luck!
